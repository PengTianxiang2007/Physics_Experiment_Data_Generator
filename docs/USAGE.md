# LabForm 使用说明

LabForm 根据给定的实验表格生成带标识的模拟数据。在线工作台的“使用指南”提供同一流程，并可启动独立演示工作区。

## 认识界面

左侧选择学期和实验，中间直接显示原始数据表格，右侧设置实验参数、随机生成和不确定度约束。首次打开时填写区域为空；同一浏览器再次打开会恢复上次保存的工作。小屏幕可打开实验菜单，宽表格可以横向滚动。

表头、单位、合并单元格和原表预填内容来自提供的材料。当前有 13 个实验、33 张表格、836 个可填写单元格；原始材料未提供实验 02、05。

## 填入数据与锁定

直接在空格中填写读数。手动输入后该格自动锁定，生成过程会保留它。点击锁图标可以解锁；已生成的数值也可以锁定。删除内容会清空单元格。

角度支持 `35°20′` 这样的度分格式，也支持十进制度。`35.20` 表示 35.2°，**不是** 35°20′。按表头所示单位填写，不要把毫米当作米。

| 来源 | 含义 |
| --- | --- |
| 手动读数 | 用户输入的值，输入后自动锁定 |
| 模拟读数 | 模型生成的读数，默认未锁定，可再次生成 |
| 计算值 | 根据读数和模型关系计算得到的字段 |

锁定计算值也会受到保护。如果它与读数或模型冲突，需自行调整或解锁；锁定不代表该值已经通过物理一致性检查。

## 一个按钮完成生成

首次填写、修改参数或修改表格读数后，都点击同一个“生成数据”按钮。程序会依据最新仪器参数、锁定读数与不确定度要求，生成或更新全部未锁定读数和计算栏；手动填写或主动锁定的值保持不变。

需要保留某个生成值时，先点击它旁边的小锁。若锁定了大部分表格，能够变化的范围也会很小。约束互相矛盾时，程序会保留锁定值并显示提示。

## 参数、仪器与随机种子

每个实验的参数不同，例如波长、光栅线密度、顶角、仪器分辨率等。修改参数会自动将它设为固定约束。取消固定后，模型可使用已有读数反推该参数；推断值会写回参数栏。取消固定不会将数值恢复默认。

噪声控制模拟读数的随机扰动幅度，各实验按自身模型将其换算到读数。噪声不是相对误差，也不是不确定度目标。约束搜索可能降低可调扰动，但不会修改锁定数据或固定参数。

随机种子是可选项。留空时，每次点击“生成数据”都会自动选择新种子；填写后固定使用该种子。页面另行显示本次生成使用的种子。清空输入框即可恢复自动随机。

相同种子只在锁定数据、参数值与固定状态、噪声和不确定度选项均相同时复现同样的结果。需要完整复现时，应保留生成前的 JSON 备份。旧项目中已保存的种子按固定种子恢复，避免改变原有复现设置。

## 完整案例：分光计

### 1. 进入独立演示区

在使用指南点击案例按钮，或在工作台地址后添加 `?demo=spectrometer`。演示工作区使用独立存储，不覆盖普通工作区。也可以下载 `/examples/spectrometer-start.json`，通过 JSON 导入恢复案例起点。导入会替换当前工作区的数据，请先备份需要保留的内容。

### 2. 预填两条读数

选择实验 09 分光计。在第一张表第一组左侧的两个游标位置填写：

| 游标 | 读数 |
| --- | --- |
| V1 | `35°0′` |
| V2 | `215°0′` |

确认两格显示为锁定状态。它们是同一方向的两条游标读数，相差 180°。

### 3. 固定仪器条件并补全

| 设置 | 数值 |
| --- | --- |
| 顶角 | `60°`，固定 |
| 光栅线密度 | `600 条/mm`，固定 |
| 角度分辨率 | `1′`，固定 |
| 噪声 | `0.3%` |
| 随机种子 | `spectrometer-demo-01` |
| B 类误差限、目标上限 | 暂时留空 |

点击“生成数据”。应有 52 个已填单元格，其中 2 个手动锁定；预填的两条读数不变。查看模型与公式了解自准直顶角与光栅计算关系。自准直顶角部分使用 `A = 180° − α`。

### 4. 添加可满足的不确定度约束

选择顶角结果组，设 B 类误差限为 `0.01°`、包含因子为 `2`、相对扩展不确定度上限为 `0.1%`，然后点击“生成数据”。

以该初始条件计算，顶角平均值约为 `59.9972°`，扩展不确定度约为 `0.01281°`，相对扩展不确定度约为 `0.0214%`，低于设定上限。界面显示精度可能有所舍入。

B 类误差限的单位是**所选结果量的单位**；这里是顶角的度。它并不自动等于原始仪器读数分辨率。切换结果组会清空 B 类误差限，需要按新结果的单位重新填写。

### 5. 尝试无法满足的条件

保持其他条件，将 B 类误差限改为 `1°`、相对扩展不确定度上限改为 `0.001%`，再重新生成。程序应提示无法达到目标；此时相对扩展不确定度约为 `1.9245%`。

这不是生成失败或空白结果：B 类分量已经使目标不可达，程序保留数据并报告未满足。两条手动读数仍然不变。继续操作前，将误差限和目标恢复为上一步的合理值。

### 6. 锁定、解锁与随机换组

任选一个生成的读数并锁定，清空随机种子，再点击“生成数据”，检查它保持不变而其他未锁定读数可以变化。随后解锁该格，再点击同一个按钮。也可填写原种子，但完整复现还需要恢复相同初始条件；导入案例起点再生成最直观。

### 7. 保存、恢复与导出

| 方式 | 用途 | 能否导入恢复 |
| --- | --- | --- |
| 浏览器自动保存 | 当前浏览器、当前站点继续使用 | 自动恢复 |
| JSON | 保留工作区数据、参数、锁定和来源，备份或跨设备转移 | 可以 |
| CSV | 在电子表格软件中查看与分析 | 不支持 |
| Word | 导出保留原表合并结构的文档 | 不支持 |
| 打印 / PDF | 通过浏览器打印或另存为 PDF | 不支持 |

先导出 JSON，再修改一格并导入刚才的 JSON，检查数据恢复。随后导出 CSV、Word，并打开打印预览了解表格布局。数据导出包含模拟数据标识。浏览器清除站点数据或换用不同站点地址后，不能依赖原有自动保存；重要工作请保留 JSON。

### 8. 清空与退出案例

清空当前表格或当前实验会清除相应数据，但保留参数。重置参数恢复参数默认值，但保留表格数据。结束后通过返回普通工作台退出演示区，普通工作区内容保持独立。

## 如何理解不确定度

对所选结果组，程序采用以下教学估计：

```text
uA = s / √n                 A 类标准不确定度
uB = b / √3                 矩形分布 B 类误差限 b
uc = √(uA² + uB²)           合成标准不确定度
U = k × uc                  扩展不确定度
相对扩展不确定度 = 100 × U / |平均值| %
```

目标上限限制最后一项，不是随机噪声幅度，也不是与理论值的相对误差。没有填写 B 类误差限时，结果主要反映 A 类重复性，不能视作完整的仪器不确定度。`k = 2` 不自动给出严格的 95% 覆盖概率。本工具不包含完整的仪器协方差、自由度和误差传播预算；详见 [模型说明](model-notes.md)。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 点生成后数据没有变化 | 检查是否全部锁定、固定了种子，或扰动与读数精度使结果相同；清空种子可自动换一组 |
| 修改读数后计算值仍旧 | 再次点击“生成数据”；若计算值也锁定了，需先解锁 |
| 输入提示无效 | 检查数值、度分格式、参数允许范围和表头单位 |
| 约束无法达到 | 检查 B 类分量、仪器分辨率、锁定数据和固定参数；调整有依据的条件 |
| 没有可选结果量 | 先补全足够数据，使模型能够形成结果组 |
| 换设备看不到之前数据 | 导出并导入 JSON；自动保存仅限本地浏览器和站点 |
| 找不到实验 02、05 | 原始材料未提供，不在当前覆盖范围内 |
