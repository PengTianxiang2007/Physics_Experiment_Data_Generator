# LabForm · 大学物理实验数据工作台

按照提供的 Data tables 表格结构生成大学物理实验**模拟数据**。进入实验即显示表格，可以先填写部分读数，再结合仪器参数、不确定度和随机种子补全数据。

[在线工作台](https://physics-lab-data-peng.aurora-wave-3133.chatgpt.site) · [交互使用指南](https://physics-lab-data-peng.aurora-wave-3133.chatgpt.site/guide.html) · [完整使用说明](docs/USAGE.md)

## 功能

- 覆盖上下学期 **13 个实验、33 张表格、836 个可填写单元格**，保留原表合并单元格、表头、单位和预填内容。
- 手动填写自动锁定；生成时保留锁定值。可以解锁，也可以锁定已经生成的读数。
- 按实验设置仪器和物理参数；固定参数作为约束，未固定参数可由已有读数推断。
- 只需一个“生成数据”按钮：按最新约束更新未锁定数据；种子留空时自动随机，填写种子后可复现结果。
- 指定结果量、B 类误差限、包含因子和相对扩展不确定度上限；无法满足时保留数据并说明原因。
- 展示模型、公式、假设和计算结果；区分手动读数、模拟读数和计算值。
- 浏览器自动保存；JSON 备份及恢复，CSV、Word、打印 / PDF 导出。
- 独立的分光计演示工作区，按完整案例操作，不覆盖普通工作区。

## 本地运行

安装 Node.js 20 或更高版本，在项目目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:8080>，使用指南为 <http://127.0.0.1:8080/guide.html>。不需要安装依赖或构建；Windows、macOS、Linux 均可使用。更换端口：

```sh
npm start -- --port=8081
```

应用使用 ES 模块和 JSON 加载，请通过上述服务器打开，不要直接双击 HTML。服务器只提供 `dist/` 内容，并只监听本机地址。

## 一个完整案例：分光计

在指南中选择“打开案例工作台”，或打开 `/?demo=spectrometer`。演示区与普通工作区分别保存。

1. 第一张表第一组左侧的两条游标读数分别填入 `35°0′` 和 `215°0′`；它们会自动锁定。
2. 固定顶角 `60°`、光栅线密度 `600 条/mm`、角度分辨率 `1′`，将噪声设为 `0.3%`，随机种子设为 `spectrometer-demo-01`。
3. 点击“生成数据”，得到 52 个已填单元格，2 个手动锁定值保留。
4. 选择顶角结果组，设 B 类误差限 `0.01°`、包含因子 `k = 2`、相对扩展不确定度上限 `0.1%`，再次点击“生成数据”。此案例顶角平均值约 `59.9972°`，相对扩展不确定度约 `0.0214%`，满足目标。
5. 将 B 类误差限改为 `1°`、上限改为 `0.001%` 再生成，会明确提示无法满足；锁定读数保持不变。
6. 恢复合理条件，试用锁定 / 解锁、随机换组、JSON 备份恢复和各项导出。逐步说明见 [完整使用说明](docs/USAGE.md)。

## 约束与不确定度的含义

每次点击“生成数据”，都会根据当前约束更新所有未锁定读数和计算值，保留手动填写及锁定的数据。修改参数会自动固定该参数；取消固定允许后续推断，不会恢复默认值。清空数据和重置参数是两个独立操作。

不确定度对选定的结果组计算：`uA = s/√n`；用户填写的 B 类误差限 `b` 按矩形分布换算为 `uB = b/√3`；`U = k√(uA² + uB²)`。目标是 `100U/|平均值|` 的上限。B 类误差限使用**所选结果量的单位**，切换结果组会清空它。`k = 2` 不自动代表严格的 95% 覆盖概率；这里是教学用途的条件估计，并非完整的仪器误差传播与协方差预算。具体模型限制见 [模型说明](docs/model-notes.md)。

随机种子留空时，每次生成自动换一组；填写种子后固定使用它，页面另行显示本次生成的种子。相同结果的复现需要锁定数据、参数值与固定状态、噪声和不确定度选项也一致。数据仅保存在当前浏览器和站点地址下，跨设备或备份请导出 JSON。导出文件带有模拟数据标识。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `dist/index.html`、`app.js`、`styles.css` | 工作台界面 |

| `scripts/serve.mjs` | 零依赖本地静态服务器 |
| `tests/` | 模型和静态服务器回归检查 |
| `docs/` | 使用、模型、覆盖和 GitHub 交付说明 |
